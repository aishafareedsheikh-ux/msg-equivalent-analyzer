# MSG-Equivalent Analyzer

An interactive, browser-based calculator for predicting naturally occurring MSG-equivalent content in spice formulations.

## Overview
Supports quality control and formulation assessments, running entirely via a single standalone HTML file.

## Open Research Software & Citation
Accompanies the research manuscript on naturally occurring monosodium glutamate.
* **Zenodo Software Record / DOI:** Linked via standard Zenodo badges (`10.5281/zenodo.22045295`).

## How to Use
1. Download `msg_calculator_interactive.html`.
2. Open in any modern web browser to input ingredient weights.
