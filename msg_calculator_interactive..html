Scope note: browser-based demo build of the calculator described in the supplementary materials — same weighted-sum engine (contribution = natural MSG% × quantity fraction), same 39-spice reference dataset plus the MSG calibration standard, a lighter approximate string matcher for ingredient name resolution (no LLM disambiguation step here; this build runs entirely client-side, with no server request or external data transfer). For the full Python/Streamlit version with tests, the validation report, and the editable CSV database, see msg_calculator.zip. Uncertainty band and the "No MSG Added" compliance threshold are both configurable modelling choices, not values drawn from replicate measurements or regulatory text — informational only.
